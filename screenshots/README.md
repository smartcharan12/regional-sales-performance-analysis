# Screenshots

> This folder is for **real Power BI screenshots only**. The Python-rendered design mockups live in [`powerbi/mockups/`](../powerbi/mockups/) and must not be copied here.

Power BI Desktop runs only on Windows, so the dashboard has to be built by hand from
[`powerbi/Dashboard_Design.md`](../powerbi/Dashboard_Design.md).

After building it, export one image per page here:

| File | Page |
|---|---|
| `01_executive_overview.png` | Executive Overview |
| `02_regional_performance.png` | Regional Performance |
| `03_product_performance.png` | Product Performance |
| `04_customer_performance.png` | Customer Performance |
| `05_profitability_discount.png` | Profitability & Discount |

Then add the Executive Overview image to the README's *Screenshots* section.
Before taking screenshots, check the cards against the expected values in
[`DAX_VALIDATION_CHECKLIST.md`](../powerbi/DAX_VALIDATION_CHECKLIST.md).
