### LinkedIn project description
**Title:** Regional Sales Performance Analysis (Python · SQL · Power BI)

**Description (≈ 600 characters):**
> End-to-end analytics project on a reproducible, synthetic Superstore-style dataset (11.5K order lines, 2021–2024). I cleaned the data in Python with a fix-before-delete approach (275 values repaired, 99.1% of rows kept), verified by 10 automated tests against ground truth. I then analysed why 2024 profit fell 6.6% while sales grew 6.7%. Deep discounts (≥ 30%) were loss-making in total, and one region's low margin was associated with heavier discounting. The results were cross-checked in a MySQL star schema (identical to the cent), and I ⟨designed⟩ a 5-page Power BI dashboard with 31 DAX measures.

**Skills to tag:** Python · pandas · SQL · MySQL · Power BI · DAX · Data Cleaning · Exploratory Data Analysis · Data Modeling · Business Analysis
